Read before using these records

A listed facility is not automatically confirmed to be open or available during an emergency. Source descriptions, coordinate verification, and live operating status are different things.

Records without verified coordinates will remain in the directory but will not be represented as confirmed map locations. Capacity and contact details will only appear when supplied by a source.

PROJECT INFORMATION

About AGOS

Analytics-driven geospatial observation and flood support for Bataan.

System scope

AGOS brings together weather forecasts, flood-related observations, terrain-derived indicators, candidate zones, and evacuation resources in one interface.

Data interpretation

Weather forecasts are model outputs for configured coordinates. Terrain-derived indicators describe landscape characteristics. Flood observations and candidate zones are separate datasets and must be interpreted according to their sources and validation status.
